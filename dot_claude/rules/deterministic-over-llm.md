# 決定論層と LLM の分業

スキル・workflow・agent を組むとき、**確定できる処理を LLM の prompt に委ねない。** 件数集計・モード分岐・lint・証跡の照合・フォーマット強制・閾値判定はコードで実装し、LLM には正解が一意に決まらない判断（命名・洞察の発見・意味解釈・設計トレードオフ）だけを残す。

- 判定: 迷ったら **「LLM が嘘をついても script が検出できる形か」** を問う。検出できないなら、確定処理を LLM に渡している。
- 接地: prompt 層に置いた件数集計・命名ゲート・モード封鎖が自己申告依存で drift し、harvest-pipeline / plan-pipeline でコードへ移した（2026-06-13）。
